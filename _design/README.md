# Design work for the new griffinbrodman.com

Not served by the site (Jekyll skips folders that start with `_`).

- `BRIEF.md`: the content and quality brief the Arcane and Koi Pond builds were made from.
- `mocks/`: the design canvas (lo-fi directions A–D, five styles of D, mid-fi Arcane / Koi / Notebook). `canvas.json` lays out the `.dc.html` artboards.
- `reviews/`: reviewer feedback rounds for Koi Pond (the Arcane rounds were relayed directly).
- `tools/`: Playwright scripts used to screenshot and review the builds (`shoot.js`, `r.js`, contrast sampling in `aa*.js`).

The finished builds live in `/test/arcane/` and `/test/koi/`.
