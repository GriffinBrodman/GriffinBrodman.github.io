# web/css/

| File | Purpose |
|------|---------|
| `daybook.css` | The daybook strip (`js/daybook.js`): parchment frame with gilt corners, sky band, activity blocks and notes, hour ruler, night cap, caption list, and the narrow-container column layout |
| `road.css` | The road pieces (`js/road_scenes.js`, `road_art.js`, `road_replay.js`): the strip behind a daybook road stretch, traveller bust frames and the vignette player |
| `echo.css` | The Daily Echo (`js/views_echo.js`): the sticky wooden clock with its sky band, the crews' tile grids (2 columns on a phone), the moments list, the bar that rides on a replay opened from it, and the Replays page's way in |
| `town.css` | A town day's scenes: the act looping along a daybook tile's foot, the player and its captions (hidden on a phone, where the full line sits under the player) |
| `app.css` | All site styles (dark fantasy UI, parchment newspaper panels, pixel fonts; the top block is the embedded "League Five" 5 from `tools/font_five.py`) |
| `places.css` | The Places & Travellers page (`js/views_places.js`, loaded lazily): sticky tabs, the found count, road groups in columns of place cards (picture, chips, best story), unfound silhouettes, traveller cards with story dots, the hooded unmet card and the night-blue card for night-only walkers |
| `pages.css` | The Roster's ranked list and sort chips, the Replays index, the great event's page, the Map's mode tabs and dungeon table, History's four sections, and the Guide's "?" links and lit entry |
| `dungeon.css` | The dungeon page (`js/views_dungeon.js`): floor stack, floor sheet and pins, margin notes in each hero's hand (`.hand-<hand>`), room cards, the Spoils list (`.dg-spoils-list`: one row per find with its sprite, name, finder and day, a single column on phones), the replay's token, inset and loot auras; and the Kit's belt/gloves/boots row |
