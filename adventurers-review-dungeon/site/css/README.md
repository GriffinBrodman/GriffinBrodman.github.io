# web/css/

| File | Purpose |
|------|---------|
| `daybook.css` | The daybook strip (`js/daybook.js`): parchment frame with gilt corners, sky band, activity blocks and notes, hour ruler, night cap, caption list, and the narrow-container column layout |
| `app.css` | All site styles (dark fantasy UI, parchment newspaper panels, pixel fonts; the top block is the embedded "League Five" 5 from `tools/font_five.py`) |
| `dungeon.css` | The dungeon page (`js/views_dungeon.js`): floor stack, floor sheet and pins, margin notes in each hero's hand (`.hand-<hand>`), room cards, the Spoils list (`.dg-spoils-list`: one row per find with its sprite, name, finder and day, a single column on phones), the replay's token, inset and loot auras; and the Kit's belt/gloves/boots row |
