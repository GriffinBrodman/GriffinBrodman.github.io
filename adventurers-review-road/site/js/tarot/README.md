# web/js/tarot/

Generated by `tools/tarot_cards.py build`; never edited by hand. Each file sets `window.TarotCardData[<deck>]` to a list of PNG data URIs, one per card in `TarotCards.meta.order`, then the back. `TarotCards.load(deck)` loads it on demand.

| `witch-burnt.js` | Wood-burned (Veldrock) |
| `witch-gilt.js` | Gilt and ink (Carrbridge) |
| `witch-oilcloth.js` | Oilcloth Sea linocut (Saltmarrow) |
