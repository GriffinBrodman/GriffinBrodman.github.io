## Load order (`web/index.html`)

Plain `<script>` tags, no modules and no build step, so everything works from `file://`. Order matters:

1. `data/static.js`, `data/league.js` (written by `league/export.py`): fill `window.LD.static` and `window.LD.league`. Per-hero, per-party and per-fight files (`data/hero/<id>.js` and so on) are loaded on demand by `App.load`.
2. `settings.js` (`Settings`, first: everything that moves or makes a sound reads it), `audio.js` (defines `Sound`; uses only WebAudio), `speech.js` (`Speech`), `town_music.js` (`TownMusic`; its own WebAudio context, reads the `al.sound` settings, needs nothing else), `art.js` (`Art`), `mount_art.js` (`MountArt`, right after `art.js`, which it needs at load), `daybook.js` (`Daybook`, also needs `art.js` at load), `paint.js` (`Paint`), `beasts.js` (`Beasts`), `anim.js` (`Anim`), `scenes.js` (`Scenes`), `town_scenes.js` (`TownScenes`), `wild_scenes.js` (adds to `TownScenes`, so right after it), `battlefield.js` (`Battlefield`, needs both), `fight_fx.js` (`FightFX`), `fight_director.js` (`FightDirector`, uses `FightFX` when drawing), `tavern.js` (`Tavern`), `camp.js` (`Night`, after `tavern.js`), `ballad.js` (`Ballad`, after `tavern.js`), `isle.js` (`Isle`). These reference each other only inside functions (`Art` calls `Paint` and `Beasts` when drawing, `Scenes` calls `Isle` and `Anim`, `Night` calls `Tavern` and, when present, `Anim`), so the order among them is not load-critical, but all must load before `app.js`.
3. `app.js` (`App`; reads `LD`, builds lookup tables, registers nothing yet), `views.js` (registers the main routes with `App.route` and publishes `Views`, its shared helpers), the `views_<page>.js` route files (each registers one route and reads `Views`; `views_settings.js` also needs `Settings`, `Tavern` and `Speech`), `replay.js` (`#/fight/<id>`), `quiz.js` (`#/join`).
4. The inline `App.start()` runs the router, so every route must be registered before it.

Each file is one IIFE that publishes one global. Files only use globals defined above them, except `Sound`, which `app.js` and `replay.js` guard with `window.Sound`. `replay.js` also draws without `FightFX` or `skill_fx` (plain stand-in effects), so either can be missing.
