Loot Goblin

They get the glory. You get the leftovers. You are Gorblo, the party's goblin: search the crypt they just smashed through, take what fits, crank the gate when you're done.

Download for Windows (35 MB) Download for Mac (60 MB)

Windows: unzip and run LootGoblin.exe. It's unsigned, so SmartScreen may warn you: click "More info" → "Run anyway".
Mac (Intel or Apple Silicon): unzip and open Loot Goblin.app. It isn't notarized, so macOS will block it the first time: go to System Settings → Privacy & Security, scroll down and click "Open Anyway". If it says the app is damaged, run xattr -cr "Loot Goblin.app" in Terminal from the folder it's in.
Controls: WASD move, mouse look, E use, C crouch, Tab sack, Esc menu.
